Clipboard Reading Statement

Last Updated: September 2026  |  Android 12+ & iOS 14+ Privacy Compliant

1. Purpose & Trigger Scope

AirBox is committed to protecting your personal data and ensuring full transparency. This statement details the specific and limited scope of clipboard access utilized by the AirBox application strictly for share link detection.

Why Does AirBox Read the Clipboard?

  • Automatic Share Link Detection: When you copy an AirBox share link from another messaging application, email, or website, AirBox detects the copied link upon opening the app.
  • One-Tap File Opening & Preview: Automatic detection eliminates the need to manually copy, search, and paste lengthy URLs into the application.
  • Targeted Domain Verification: The application checks only for recognized AirBox domain formats (such as airbox.one/s/... or share links).
  • Zero Background Access: Clipboard inspection occurs strictly when the application is launched or brought from the background into the foreground.

1.1 User-Initiated Share Workflows

Clipboard reading is designed exclusively to facilitate smooth file receiving workflows when a user has deliberately copied a file share link provided by another user or external source.

1.2 Foreground Execution Only

AirBox does not maintain background clipboard listeners. Clipboard text is queried strictly once when you actively switch to or launch the AirBox application.

2. Technical Safeguards & Data Filtering

We implement strict technical guardrails to ensure sensitive personal data in your clipboard is never accessed or exposed:

2.1 Local Device Inspection Only

  • In-Memory Parsing: The clipboard string is inspected purely within local application memory on your mobile device.
  • No Server Transmission: Clipboard contents are never sent to remote servers for scanning or indexing.
  • No Local Storage: Raw clipboard text is never saved to local SQLite databases, cache files, or log files.

2.2 Immediate Discard of Non-AirBox Content

  • Pattern Matching: The application checks whether the string starts with verified AirBox URL schemes or share tokens.
  • Instant Destruction: If the clipboard contains private messages, passwords, financial details, or regular text, it is immediately discarded from memory.
  • Zero Analysis: Non-matching text is never parsed, tokenized, or analyzed in any manner.

2.3 Network Security Safeguards

  • Zero Telemetry on Clipboard: Analytics services and telemetry trackers do not receive clipboard strings.
  • TLS 1.3 Communication: Only verified file identifiers extracted from valid share links are resolved via encrypted TLS channels.

3. User Privacy, Transparency & Inquiries

You maintain complete control over how shared links are handled in the application:

3.1 Explicit Confirmation Dialog

Whenever a valid AirBox share link is detected, a confirmation dialog appears displaying the file details with "Open File" and "Cancel" buttons. No file is opened or imported without your explicit interaction.

3.2 Native OS Privacy Notifications

AirBox fully complies with Android 12+ and iOS 14+ clipboard privacy toasts. Your mobile operating system will display its native privacy banner whenever the clipboard is accessed.

3.3 Zero Profiling or Third-Party Sale

We do not build advertising profiles, track personal clipboard history, or monetize clipboard information. Clipboard access exists exclusively for the single functional purpose of opening shared links.
